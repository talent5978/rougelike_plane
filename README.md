# 🏰 魔法学院冒险记

一个完整的多页面RPG冒险游戏，具有丰富的成长系统和策略战斗体验。

## 🎮 游戏特色

### 核心系统
- **回合制战斗** - 策略性十足的战斗系统
- **完整成长体系** - 等级、经验、属性提升
- **丰富装备系统** - 武器、护甲、药水等多种装备
- **技能魔法系统** - 火球术、治疗术、冰锥术等魔法技能
- **实时排行榜** - 与其他玩家竞技排名

### 游戏内容
- **多样化敌人** - 史莱姆、哥布林、骷髅战士、火焰精灵、冰霜巨人、暗影龙等
- **装备商店** - 购买武器、护甲和药水
- **任务系统** - 完成各种挑战任务获得奖励
- **成就统计** - 击杀数、总伤害、获得金币等数据统计

### 技术特点
- **前后端分离** - Node.js + Express后端，HTML5前端
- **实时通信** - Socket.IO支持实时消息推送
- **用户系统** - JWT身份验证，安全的用户管理
- **响应式设计** - 完美适配PC和移动设备
- **数据持久化** - 玩家数据实时保存

## 🚀 快速开始

### 环境要求
- Node.js 14.0+
- npm 6.0+

### 安装依赖
```bash
npm install
```

### 启动游戏服务器
```bash
# 生产环境
npm start

# 开发环境（自动重启）
npm run dev
```

### 访问游戏
打开浏览器访问：`http://localhost:3000`

## 🎯 游戏玩法

### 1. 注册账号
- 创建你的魔法师角色
- 选择用户名和密码

### 2. 探索战斗
- 选择不同等级的怪物挑战
- 使用攻击、技能或逃跑策略
- 击败敌人获得经验和金币

### 3. 角色成长
- 升级提升属性：攻击力、防御力、生命值、魔法值
- 学习新的魔法技能
- 查看详细的战斗统计

### 4. 装备强化
- 访问魔法商店购买装备
- 使用药水恢复生命和魔法
- 装备武器和护甲提升战斗力

### 5. 竞技排名
- 查看实时排行榜
- 与其他玩家比拼等级和成就
- 争夺魔法学院第一名

## 🛡️ 游戏系统详解

### 战斗系统
- **回合制** - 玩家和怪物轮流行动
- **技能消耗** - 使用魔法需要消耗魔法值
- **伤害计算** - 考虑攻击力、防御力和随机因素
- **经验奖励** - 击败敌人获得经验和金币

### 成长系统
- **等级提升** - 经验满足要求自动升级
- **属性增长** - 升级时所有属性都会提升
- **技能学习** - 默认掌握火球术和治疗术
- **装备强化** - 通过装备提升战斗能力

### 经济系统
- **金币获得** - 击败怪物获得金币奖励
- **商店购买** - 使用金币购买装备和药水
- **物品使用** - 药水可以恢复生命值和魔法值
- **背包管理** - 查看和使用背包中的物品

## 📊 数据统计

游戏会记录以下统计数据：
- 击败怪物数量
- 造成总伤害
- 获得总金币
- 完成任务数
- 在线时长

## 🔧 技术架构

### 后端技术栈
- **Node.js** - 服务器运行环境
- **Express** - Web框架
- **Socket.IO** - 实时通信
- **JWT** - 身份验证
- **bcryptjs** - 密码加密

### 前端技术栈
- **HTML5** - 页面结构
- **CSS3** - 样式设计（渐变、动画、响应式）
- **JavaScript** - 交互逻辑
- **Socket.IO Client** - 实时通信

### 数据存储
- 使用内存Map存储（演示用）
- 生产环境建议使用MongoDB或MySQL

## 🎨 界面设计

- **现代化UI** - 渐变色彩、圆角设计、阴影效果
- **响应式布局** - 适配各种屏幕尺寸
- **流畅动画** - hover效果、过渡动画
- **直观操作** - 清晰的按钮和信息展示
